# VGK Log Reader

VGK Log Reader decrypts and parses Riot Vanguard’s encrypted logs

The web app makes the logs readable and lets you trace Vanguard events, game sessions, crashes, etc

### **Open VGK Log Reader at [spookier.github.io/vgk](https://spookier.github.io/vgk/)**

---

Select **Try demo data** on the start screen to explore with sample logs
